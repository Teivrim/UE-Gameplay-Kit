## Что внутри

- Три полностью раздельных GameMode: combat, сайдскроллер, платформер
- StateTree + EQS-контексты (Player, Danger) для ИИ противника
- Спавнер, чекпоинты, активируемые объекты, разрушаемые ящики
- Комбо через три AnimNotify, полоса жизни, камера с зумом
- JumpPad, движущиеся платформы, pickup, мягкие платформы
- Модульная структура папок — подходит как стартовый шаблон проекта

## Кому подойдёт

Студенты и инди на UE5, которым нужен рабочий геймплейный каркас вместо пустого проекта

## Чем отличается от аналогов

На маркетплейсе нет готового набора из трёх разных GameMode с StateTree-логикой ИИ на C++.
